#  University Major Search Website

A modern web platform that helps Algerian students explore university majors and their **2025 admission scores**.

Users can search by major name or admission score, filter results by stream, university, and score range, and easily find suitable academic options based on their Baccalaureate average.

##  Features

-  Search for university majors by **name** or **admission score**
-  View the **2025 admission scores** for each major
-  Filter majors by **university**
-  Filter majors by **academic stream**
-  Filter results using a **minimum and maximum score range**
-  Fully responsive design for mobile and desktop
-  Fast, clean, and user-friendly interface
-  Modern UI/UX design
-  Arabic-friendly interface

##  Tech Stack

- HTML5
- CSS3
- JavaScript
- React
- Tailwind CSS
- Vite

##  Getting Started

### Prerequisites

Make sure Node.js and npm are installed:

```bash
node -v
npm -v
```

### Installation

```bash
git clone [https://github.com/Ynsaid/University-Major-Search-Website.git](https://github.com/Ynsaid/University-Major-Search-Website.git)
cd University-Major-Search-Website
npm install
```

### Run the Project

```bash
npm run dev
```

Then open:

```text
http://localhost:5173
```

##  Build for Production

```bash
npm run build
```


##  Project Goal

This project helps Algerian high-school students and future university students:

- Discover available university majors
- Check the 2025 admission scores
- Filter majors according to their Baccalaureate average
- Find suitable universities based on their stream and score
- Make more informed decisions about their academic future

##  How It Works

1. Enter a major name or an admission score.
2. Choose a university, stream, or score range.
3. Browse the matching majors and their 2025 admission scores.
4. Explore the results and compare available options.
